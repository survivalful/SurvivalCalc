# Security Policy

## Supported Versions

The following versions of SurvivalCalc are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discovered a security vulnerability in SurvivalCalc, please **do not** report it publicly as a GitHub Issue.

Instead, send an email to: **team@survivalful.de**

Please include the following information:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

**What happens after your report?**
- Confirmation of receipt within **48 hours**
- Status update within **7 days**
- If confirmed: coordinated disclosure after a fix is released
- If declined: a brief explanation

Thank you for helping keep SurvivalCalc secure!

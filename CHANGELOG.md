# Changelog

All notable changes to SurvivalCalc for Windows will be documented here.

## [1.0.2] - 2026-03-24
### Added
- Color band resistance calculator (4-ring and 5-ring)
- Power calculations (P = U·I, P = I²·R, P = U²/R)

### Fixed
- Minor UI improvements

---

## [1.0.1] - 2026-03-24
### Added
- Automatic update checker with download dialog
- Multi-language support (DE/EN)
- Persistent settings via JSON
- Calculation history via SQLite

### Fixed
- Minor bug fixes

---

## [1.0.0] - 2026-03-24
### Added
- Initial release
- Standard calculator with keyboard support
- Area calculations (Square, Rectangle, Circle, Triangle, Trapezoid, Cylinder, Sphere, Cone)
- Volume calculations (Cube, Rectangular prism, Cylinder, Cone, Sphere, Tetrahedron, Trapezoidal prism)
- Electricity calculations (Voltage, Current, Resistance)
- Dark/Light mode
- Unit system (pm → Gm) with automatic conversion
- Adjustable rounding (0–20 decimal places)
